# 股票截图管理系统 - 最终需求文档 v2.0（安卓版）

## 一、项目概述

开发一款 **Android 原生应用**，用于自动截取手机股票行情软件的屏幕，管理每日股票截图，记录交易价格，并提供浏览、查询、标记等功能。

**技术栈：**
- 语言：Kotlin
- UI 框架：Jetpack Compose
- 数据库：Room（SQLite 封装）
- 截图方案：MediaProjection API（Android 5.0+）
- 自动化操作：AccessibilityService + UiAutomator
- 图片处理：Coil（加载/缓存）+ Bitmap
- 网络请求：Retrofit + OkHttp
- 异步：Kotlin Coroutines + Flow

**最低支持版本：** Android 8.0 (API 26)

## 二、核心功能模块

### 模块 1：主界面 - 当日股票列表

**布局说明：**
- 顶部工具栏：`TopAppBar`
  - 左侧：【标记按钮】（星形图标）
  - 中间：【当前日期显示 + 点击弹出日期选择器】
  - 右侧：【三点菜单按钮 `⋮`】
- 主体区域：`LazyColumn` 列表展示当日所有有图片的股票

**列表字段：**

| 序号 | 股票代码 | 股票名称 | 买入价 | 卖出价 | 获利比例 |
|------|----------|----------|--------|--------|----------|
| 自动编号 | 文本 | 文本 | 可编辑/自动填充 | 可编辑/自动填充 | 自动计算 |

**交互规则：**
- 点击某行 → 进入全屏图片查看模式
- 买入价/卖出价：点击单元格弹出 `AlertDialog` 输入框手动编辑，也可通过菜单自动更新
- 获利比例显示规则：
  - 买入价 = 0 或 卖出价 = 0 → 显示 `"--"`
  - 两者均 > 0 → 计算 `(卖出价 - 买入价) / 买入价 × 100%`，保留两位小数
  - 正数显示绿色，负数显示红色，零显示灰色

---

### 模块 2：标记功能

**标记按钮行为：**
- 默认状态（空心星 ⚫）：显示当日所有有图片的股票
- 点击切换为（实心星 ⭐）：只显示当前日期下被标记过的股票
- 再次点击恢复显示全部

**标记存储逻辑：**
- 数据库表 `marks`：`id`, `stock_code`, `date`, `is_marked`
- 一只股票在不同日期可有不同标记状态，互不影响
- 唯一索引：`(stock_code, date)`

---

### 模块 3：日期选择

**日期选择器行为：**
- 弹出 Material DatePicker 或自定义日历弹窗
- 有图片数据的日期：显示红点 + 可选
- 无图片数据的日期：灰色 + 不可选
- 选中日期后，主列表刷新为该日期的股票数据

---

### 模块 4：全屏图片查看器

**触发方式：**
- 主列表点击某只股票
- 搜索页点击某条结果

**界面设计：**
- 全屏显示当前股票在当前日期下的截图
- 使用 `ViewPager2` + `PhotoView` 支持缩放和左右滑动
- 左右滑动：切换同一日期的上一只/下一只股票图片
- 排序规则：**按股票代码升序排列**
- 循环模式：第一只的"上一只"跳到最后一只，最后一只的"下一��"跳到第一只
- 底部显示：进度指示器 `"3 / 15"`
- 底部同时显示：当前标记状态（空心星/实心星），**点击星星图标切换标记**
- 顶部显示：股票代码 + 股票名称
- 搜索结果进入时：顶部额外显示日期信息，格式 `"2026/06/26  第2条/共5条"`
- 退出：返回键 / 左上角返回箭头

### 模块 5：三点菜单（PopupMenu）

#### 5.1 搜索功能
- 点击后进入搜索页面
- 顶部搜索栏：支持模糊搜索股票代码或股票名称（实时过滤）
- 结果列表字段（**只读，不可编辑**）：

| 序号 | 日期 | 股票名称 | 买入价 | 卖出价 | 获利比例 |
|------|------|----------|--------|--------|----------|

- 排序规则：**按日期倒序排列**，最新日期在最前面
- 点击任意一行 → 打开全屏图片查看器
- 查看器中左右滑动：按搜索结果列表顺序切换（即日期倒序）

#### 5.2 买入价更新
- 从系统设置中配置的数据源（HTTP API）获取当日开盘价
- 批量更新当前列表中所有股票的"买入价"字段
- 更新后自动重算获利比例
- 网络失败时弹 Snackbar 提示

#### 5.3 卖出价更新
- 从系统设置中配置的数据源获取当日收盘价
- 批量更新当前列表中所有股票的"卖出价"字段
- 更新后自动重算获利比例
- 网络失败时弹 Snackbar 提示

#### 5.4 获取当日列表（自动化截图任务）

**前置条件：**
- 设置页面已完成控件参数配置
- 已授予无障碍服务权限 + 屏幕录制权限
- 目标股票 APP 在前台运行

**执行流程：**
1. 弹出悬浮窗控制按钮（含"停止"按钮 + 当前进度文字）
2. 通过 AccessibilityService 读取当前页面指定控件的文本内容，获取股票代码
3. **重复判断逻辑：**
   - 维护一个本次任务已处理的股票代码列表
   - 遇到重复代码 → 记录"跳过重复：xxx"
   - **第 2 次遇到重复**（即同一个代码出现 2 次）→ 自动终止任务，弹 Toast "检测到重复，任务已自动停止"
4. 使用 MediaProjection 截取当前屏幕
5. 保存图片至 `内部存储/StockScreenshots/{股票代码}/{日期}_{时间戳}.png`
   - 文件夹不存在则创建，已存在则直接使用
6. 将股票代码、图片路径、日期、股票名称写入 Room 数据库
7. 通过 AccessibilityService 模拟点击"下一只"按钮
8. 等待预设延迟（默认 2000ms，可在设置中调整）
9. 循环执行，直到用户点击"停止"或触发重复终止条件

**异常处理：**
- 截图失败：重试 3 次，仍失败则跳过并记录日志
- 获取代码为空：暂停任务，弹通知提示用户手动操作后点击"继续"
- 来电/切出 APP：任务暂停，回来后提示是否继续

**控件识别备用方案（按优先级）：**
1. 通过 AccessibilityNodeInfo + viewId 获取文本
2. 通过正则匹配页面文本内容（如 `\d{6}` 六位数字代码）
3. OCR 识别指定区域（集成 ML Kit Text Recognition）
4. 用户手动输入当前股票代码（保底方案）

## 三、数据库设计（Room）

### Entity 1: StockRecord
```kotlin
@Entity(tableName = "stock_records")
data class StockRecord(
    @PrimaryKey(autoGenerate = true) val id: Long = 0,
    @ColumnInfo(name = "stock_code") val stockCode: String,
    @ColumnInfo(name = "stock_name") val stockName: String?,
    @ColumnInfo(name = "buy_price") val buyPrice: Double = 0.0,
    @ColumnInfo(name = "sell_price") val sellPrice: Double = 0.0,
    @ColumnInfo(name = "profit_rate") val profitRate: Double = 0.0,
    @ColumnInfo(name = "date") val date: String, // yyyy-MM-dd
    @ColumnInfo(name = "image_path") val imagePath: String,
    @ColumnInfo(name = "created_at") val createdAt: Long = System.currentTimeMillis()
)

// 同一股票同一天可能有多张截图，所以 stock_code + date 不设为唯一
// 查询时按 created_at 取最新一条作为列表展示
```

### Entity 2: Mark
```kotlin
@Entity(
    tableName = "marks",
    indices = [Index(value = ["stock_code", "date"], unique = true)]
)
data class Mark(
    @PrimaryKey(autoGenerate = true) val id: Long = 0,
    @ColumnInfo(name = "stock_code") val stockCode: String,
    @ColumnInfo(name = "date") val date: String,
    @ColumnInfo(name = "is_marked") val isMarked: Boolean = false
)
```

### Entity 3: AppSetting
```kotlin
@Entity(tableName = "app_settings")
data class AppSetting(
    @PrimaryKey val key: String,
    @ColumnInfo(name = "value") val value: String
)
```

**关键配置项：**

| key | 说明 | 默认值 |
|-----|------|--------|
| data_source_type | 数据源类型（api/manual） | api |
| api_base_url | 价格 API 地址 | "" |
| api_key | API 密钥 | "" |
| target_app_package | 目标股票 APP 包名 | "" |
| code_view_id | 股票代码控件 ID | "" |
| next_button_id | 下一只按钮控件 ID | "" |
| screenshot_delay_ms | 截图后延迟(毫秒) | 2000 |
| ocr_enabled | 是否启用 OCR 备用 | false |

## 四、附加功能

### 4.1 批量删除
- 长按列表中的某一项 → 进入多选模式（顶部出现删除栏）
- 勾选多个股票后，点击底部"删除"按钮
- 弹出确认对话框："确定删除选中的 N 条记录及其图片？"
- 确认后：删除数据库记录 + 删除对应图片文件

### 4.2 数据导出/导入
- 导出 CSV：包含股票代码、日期、名称、买入价、卖出价、获利比例
- 导出图片：按日期打包为 ZIP 文件
- 导入：恢复之前导出的 CSV 数据

## 九、注意事项

1. 最低支持 Android 8.0 (API 26)，适配至 Android 14
2. 国产 ROM 无障碍服务可能被限制，需做兼容提示
3. Android 10+ 使用应用私有目录存储截图，无需申请存储权限
4. 截图任务绑定 Foreground Service + 常驻通知，防止被杀
5. 隐私合规：截图数据仅本地存储，明确告知用户
6. 所有网络请求需设置超时和重试机制
7. 数据库操作统一在 IO 线程执行，UI 通过 Flow 观察数据变化
