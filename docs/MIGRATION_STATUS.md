## 当前功能

v1.9 已有四个可共存版本 A/B/C/D、截图自动采集/浏览/筛选/备份、指标颜色/红绿点检测及调参、最高价更新、采集归属所选日期、多行备注和表格固定列。

最高价更新使用记录日之后 N 个自然日，N 默认 10，不含记录当天；更新卖出价并按每张截图买入价重算收益。东方财富失败时使用腾讯/新浪备用日 K，行情缺失或区间无法确认覆盖时保留原价并显示原因。

诊断日志默认关闭，可随时启停、查看、导出、分享、清空；四版分别保存在自己的应用私有目录。若手机仍无法更新最高价，在主菜单开启日志后重试并导出 .log，可继续定位手机网络/数据源问题。

具体实现规则及发布历史以 StockShotManager/RELEASE_NOTES.md 和当前源码为准。
