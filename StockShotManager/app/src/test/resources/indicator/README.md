# 指标识别回归截图

这两张图来自 2026-11-27 同一台手机、同一只股票的现场诊断。它们属于开发/回归样本，不是独立留出测试集，不能用来估计线上准确率。

- panels-capital-above-trend.png：上方分时博弈、下方趋势顶底，与当前检测器要求的顺序相反。只断言版式识别为 UNKNOWN，不据此判断股票条件。
- panels-trend-above-capital.png：用户调整为上方趋势顶底、下方分时博弈。用户已确认严格逐列整段规则（pointwise/all，any 从左向右）不符合；其他规则没有人工标签。

两图只保存指标区域，删除了与检测无关的股票名称、盘口、状态栏等内容。原图尺寸、裁剪坐标、来源 SHA-256、裁剪 SHA-256 和标签出处见 fixtures.json。裁剪不缩放、不重采样；测试在白色 1440×3200 画布的 (0,1776) 粘贴 986×728 裁剪，恢复检测区域的原始位置。

信号真实值标签与版式观察分别记录。后续增加人工标签时应保留确认来源，不得把程序输出自动当成真值。
